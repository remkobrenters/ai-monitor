# ai-monitor v1.3.1

**Equal GNOME quota card widths and optional token counts in the menu.**

## Changed

- Claude and Codex quota cards share the available width equally, regardless of
  their plan names or reset text. Narrow menus retain the stacked layout.
- Settings → Tokens → Show token counts controls the entire token usage block,
  including its separator, on GNOME and macOS. The setting is enabled by default,
  takes effect in an open menu, and retains the cached-data preference while hidden.
- Usage collection continues while token counts are hidden. Sessions,
  subscription limits, and footer actions remain available.

## Install or update

Run `./install.sh` without sudo from the local GNOME desktop, then **log out and
back in** to load the updated JavaScript. On Xorg, restarting GNOME Shell also
works. Switching the extension off and on does not reload cached JavaScript;
new settings can appear before the running menu has loaded the update.

Hooks are unchanged, so Claude and Codex need no restart and Codex handlers need
no new review. Existing settings and numeric history are retained. On macOS,
run `./install.sh` to rebuild and restart the menu bar app.

## Validation and limits

- Automated checks cover schema defaults and toggling token counts, preserving
  sessions and limits while hidden, and restoring current totals and cached data.
- Desktop tests mock GNOME APIs. The visual layout and toggle still need a
  desktop check after reloading GNOME Shell. The macOS toggle needs a macOS
  build and desktop check; it was not type-checked on Linux.
