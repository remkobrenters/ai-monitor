# ai-monitor v1.4.0

**Keep the current session and its terminal together when switching sessions.**

## Fixed

- Switching Claude or Codex sessions inside a running CLI replaces the previous
  session row and its alerts. An old "finished" entry no longer remains beside
  the current working session for the same process.
- Older hooks and subagent lifecycle events from a previous session cannot take
  its terminal binding back from the current session.
- Restarting the monitor repairs duplicate rows saved by older versions, keeping
  the latest native session and its acknowledgement state.

## Install or update

Run `./install.sh` without sudo. On Linux, the service fix takes effect when the
installer restarts the monitor; no GNOME Shell reload is needed for this fix.
On macOS, the installer also rebuilds and restarts the menu bar app.

Hooks are unchanged, so existing Claude and Codex sessions need no restart and
Codex handlers need no new review. Existing settings and numeric history are
retained.

## Validation and limits

- `make check` and `make dist` pass on Linux.
- Regression tests cover session switches, delayed hooks, duplicate recovery,
  independent terminals in the same project, and rename preservation of status,
  acknowledgement and terminal targets.
- The running Linux monitor was checked for duplicate process bindings, and its
  Codex target was verified to refer to an existing GNOME Terminal tab.
- No macOS build or desktop validation was performed for this release.
