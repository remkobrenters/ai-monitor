# ai-monitor v1.3.0

**ai-monitor now runs on macOS.**

A native menu bar app shows the same dashboard as the GNOME panel: subscription
windows, terminal sessions, subagent activity, token totals, and attention
alerts. It uses the same local service and passive Claude/Codex hooks.

## Added

- macOS 13+ support. `./install.sh` builds the menu bar app with the Xcode
  Command Line Tools, installs it as `~/Applications/AI Monitor.app`, and starts
  it and the service at login through two LaunchAgents. Uninstall and `--purge`
  remove them again.
- Click a session to select its exact Terminal.app or iTerm2 tab, once you allow
  AI Monitor to control that app. tmux panes are selected as on Linux. Other
  terminals and IDEs are brought to the front.
- A waiting session in the front Terminal or iTerm2 tab counts as seen: it is
  acknowledged and stays silent, while other tabs still alert.
- macOS notifications, the bundled sounds, Silent mode, Acknowledge agents and a
  Settings window with the same options and defaults as the GNOME preferences.
- Claude allowances on macOS are read with Claude Code's own login Keychain item.
  The token stays in memory and is never refreshed or stored by ai-monitor.

## Changed

- Process discovery, hook terminal identity and the private socket work on both
  Linux (`/proc`) and macOS (libproc and sysctl). The socket checks the
  connecting user on both platforms.
- The installer and `ai-monitor uninstall` use the Python that ran the installer
  on macOS. Linux keeps using the system Python.
- `make check` type-checks the Swift app and runs its logic tests on macOS, and
  the GNOME checks on Linux.

## Install or update

**Linux:** run `./install.sh` without sudo from the local GNOME desktop. Hooks are
unchanged, so Claude and Codex need no restart and Codex handlers need no new
review. Existing settings and numeric history are retained.

**macOS:** install Python 3.11+ (for example `brew install python`) and the Xcode
Command Line Tools (`xcode-select --install`), then run `./install.sh` from a
terminal where `claude`, `codex` and Node.js are on your PATH. Restart
Claude/Codex and trust the hooks in Codex with `/hooks`. Allow notifications, and
allow AI Monitor to control Terminal or iTerm when asked.

## Validation and limits

- Automated checks pass on Linux and macOS. On a Mac with Apple silicon and
  macOS 26, the installer, both LaunchAgents and the Keychain-based Claude
  allowance were confirmed working. The full macOS desktop checklist has not
  been recorded yet.
- Exact tab selection on macOS covers Terminal.app and iTerm2. Other macOS
  terminals cannot tell their windows or tabs apart; sound is suppressed while
  they are in front, but sessions are not acknowledged.
- The app is ad-hoc signed during installation, so macOS may ask for its
  permissions again after a reinstall. The service keeps the PATH from install
  time; run the installer again after moving the CLIs or Python.
- macOS screenshots are rendered from the app's views with sample data.
