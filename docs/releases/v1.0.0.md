# ai-monitor v1.0.0

**Your coding agents, usage limits, and attention alerts in one GNOME panel menu.**

The first release brings Claude Code and Codex monitoring together in a standalone
desktop tool. See which agent needs you, check remaining subscription allowance,
and jump back to the terminal where the work is happening.

## Included

- One shared panel indicator with per-tool allowance bars and a purple attention
  highlight behind the tool waiting for input.
- Short/weekly subscription windows, reset countdowns, and remaining Codex reset
  credits when reported by the CLI.
- Today, Week, Month, and YTD token totals. Optional cached-token counts and
  cache-hit percentages are hidden by default.
- Native session names, full working-directory paths, and status rows that open
  the matching GNOME Terminal tab or attached tmux pane/client.
- Subagent counts inside the parent session, including a waiting message while
  delegated work finishes, without adding terminal counts or input-needed alerts.
- Optional audio once, every minute, or every five minutes; three bundled effects,
  custom local files, preview, and volume controls. Automatic sound starts off.
- Sound suppression for identified focused terminal tabs/panes and a locked
  desktop. Other waiting sessions can still alert.
- Automatic Codex permission reviews stay marked as working. Input alerts require
  a short confirmation period, so requests resolved while work continues stay quiet.
- A single footer row with Silent mode, Acknowledge agents, and Settings.
- Native light/dark themes, display-scale-aware panel geometry, and a compact
  menu layout for narrower displays.
- A user-service installer and clean uninstall, preserving unrelated CLI hooks
  and settings. `--purge` also removes ai-monitor history and preferences.

## Privacy and security

Local session metadata and numeric summaries stay on the desktop; there is no
telemetry or ai-monitor account. Allowance lookups use existing provider logins.
The local socket is private to the Linux user, hooks are passive, Claude usage
requests reject redirects, and response sizes are bounded. Installer records do
not copy unrelated settings or credentials.

Source code uses the MIT license. The notification recordings retain their
Pixabay license and creator credits in `THIRD_PARTY_NOTICES.md`.

## Install or update

Extract the source archive, install the prerequisites listed in the README, and
run `./install.sh` without sudo from the local GNOME desktop. Reload GNOME Shell
or log out/in. Restart Claude/Codex; review the new Codex handlers in `/hooks`.
Existing settings and numeric history are retained.

## Compatibility and known limits

The development baseline is Ubuntu 24.04 with GNOME Shell 46. GNOME 46–50,
Xorg/Wayland, and x86-64/ARM64 are targets with the documented prerequisites;
complete hardware/desktop acceptance testing is still outstanding. Automated
tests use mocked GNOME APIs. See the README compatibility table before installing.

Exact tab integration is specific to GNOME Terminal and attached tmux clients.
Other terminal apps use best-effort window matching. Remote forwarding is not
available. Hook delivery varies by CLI release: missed subagent events can make
counts incomplete, and unsupported questions may remain marked as working.
Allowance endpoints and CLI formats can change. Token history includes only
available local records; YTD is not guaranteed to cover the entire year.
