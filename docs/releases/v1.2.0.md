# ai-monitor v1.2.0

**Click a session to bring its terminal back to the front.**

Session clicks now preserve the original click time through the local service
and asynchronous GNOME Terminal calls. This fixes terminals that selected the
right tab but stayed hidden behind a browser or another window.

## Changed

- GNOME Terminal selects the exact tracked tab with the original click time.
  When only one matching terminal window exists, ai-monitor also raises it
  explicitly through GNOME Shell.
- A tab moved between terminal windows keeps its exact screen identity. An old
  inherited window ID cannot override that selection.
- Other local terminal windows also receive the original click time. Ambiguous
  window matches still use the existing chooser.
- Version tags now publish a GitHub release automatically after the x86-64 and
  ARM64 checks pass, including these notes, an allowlisted source archive, and
  its SHA-256 checksum.

## Install or update

Run `./install.sh` without sudo from the local GNOME desktop, then reload GNOME
Shell or log out/in. Hooks are unchanged, so Claude and Codex need no restart and
Codex handlers need no new review. Existing settings and numeric history are
retained.

## Validation and limits

- The reporting user confirmed that terminal switching works on their desktop.
  This does not replace the complete desktop acceptance checklist.
- Regression tests cover delayed activation replies, zero event times, moved
  tabs, closed tabs, failed activation, and timestamp forwarding through the
  local bridge. Automated desktop tests mock GNOME's APIs.
- Exact tab activation still depends on GNOME Terminal's D-Bus integration.
  Other terminal applications retain window matching and the ambiguity chooser.
  Remote sessions are not forwarded; detached tmux sessions need attaching first.
