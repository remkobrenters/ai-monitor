# ai-monitor v1.1.0

**The terminal you are already looking at no longer asks for your attention.**

This release stops ai-monitor from alerting about the session you are working in.
A waiting agent in the focused GNOME Terminal tab now counts as seen, so the panel
stays calm while you read its reply, and it stays calm after you switch away.

## Changed

- A waiting Claude or Codex session shown in the identified focused GNOME Terminal
  tab, or in an attached tmux pane displayed there, is acknowledged automatically,
  as if you had chosen it in the menu. The purple panel highlight stops at once,
  and repeat sounds no longer resume when you move to another window.
- The focused-tab check also runs in Silent mode, so acknowledgement no longer
  depends on sound being enabled.
- Sessions waiting in other tabs, other windows, or behind the lock screen still
  alert as before.
- The menu width now follows the interface font (38em with 10px side padding)
  instead of a fixed 560px, matching other panel menus sized the same way.
  Narrow displays keep the compact layout.

## Install or update

Run `./install.sh` without sudo from the local GNOME desktop, then reload GNOME
Shell or log out/in. Hooks are unchanged, so Claude and Codex need no restart and
Codex handlers need no new review. Existing settings and numeric history are
retained.

## Known limits

- "Seen" means the tab has keyboard focus. If you step away with that tab focused,
  its session is acknowledged without an alert. The lock screen is excluded.
- Other terminal applications are matched by X11 window ID, which cannot tell tabs
  apart. They keep focused-window sound suppression but are not acknowledged.
- Desktop banners are decided before the tab check finishes and can still appear
  for the focused tab. Turn off **Show desktop notifications** to rely on the
  highlight and sound.
- The highlight can appear for a few milliseconds while the tab check runs.
- Automated tests mock GNOME's desktop APIs; the new width has not been measured
  on every Shell theme.
